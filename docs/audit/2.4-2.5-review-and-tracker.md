# 2.4 Statement / application review and 2.5 Tracker: audit

Date: 2 October 2026. Code read (`app/review/page.tsx`, `lib/writing.ts`, `app/api/review`, `app/tracker/page.tsx`, `lib/ics.ts`, `lib/store.ts`); both pages driven in Chromium at 375px with fake AI.

## 2.4 Statement / application answer review

### What it does
Paste a personal statement or an application answer (50-6,000 characters), optionally a job advert. The AI returns a 0-10 score, summary, strengths, improvements and a rewritten opening (2-3 sentences, "using only facts already given"). Free: 2 reviews a week.

### Findings
| # | Finding | Severity |
|---|---|---|
| 1 | **Not firm-aware.** It doesn't know each firm's real application questions or word limits (e.g. Barclays' ~30-minute form, PwC Flying Start via UCAS). Tailoring only happens if a job advert is pasted | High |
| 2 | Honesty guardrails are good: page says "Write it yourself… Employers want your own words"; asks students to remove names and contact details; warns some employers restrict AI help. Prompt forbids inventing achievements and marks gaps "[add detail]" | Positive |
| 3 | Rewrites only the opening, not the whole text (good for honesty). But there's no request refusal for "write my whole statement" beyond this design; the eval set includes this case | Low (to verify live) |
| 4 | No explanation of **how firms view AI-written applications** beyond one line (ISE 2025: 52% of employers worry school leavers misrepresent themselves with AI; Barclays says AI tools in assessments end the application; Deloitte treats leaked-question sites as an integrity issue) | Medium |
| 5 | Feedback criteria are generic (tailoring, evidence, motivation, structure); no firm values, no word-count check, no spelling/grammar pass | Medium |
| 6 | Real AI quality and consistency **not measured** (no key). `evals/statement-cases.json` has 12 cases: strong, generic, weak, wrong firm named, AI-sounding, injection, "write it for me", personal data, max length, Spanish | — |
| 7 | Same safety layer as interviews (moderation with support message; escaped tags); same fails-open caveat | Info |
| 8 | Browser run: works on mobile, no errors (fake AI) | Positive |

**Score: 5 / 10** (vs Intervyo's CV and cover-letter review and human statement services). Safe and honest, but generic and unmeasured.

**To reach 9+:** firm-specific question sets and word limits (pick firm and question, check length); criteria including the firm's values; spelling/grammar notes; a clear "how employers view AI" explainer; refuse to write whole statements (and test it); run the eval set.

## 2.5 Tracker

### What it does
Add an application (employer, role, closing date) → status pipeline (Interested, Applied, Online tests, Video interview, Assessment centre, Offer, Rejected) → filter by status → "closing soon" banner → export all deadlines to a calendar file (.ics) with a reminder 3 days before. Saved in the browser and, when signed in, synced to the account.

### Findings
| # | Finding | Severity |
|---|---|---|
| 1 | **Everything is typed by hand.** It doesn't use our own firm data: no "add Goldman Sachs FICC" picker with the real opening/closing dates, stages and links | High |
| 2 | Reminders: only the in-page banner and the calendar file. **No email or push reminders**, no "applications open" alerts (the thing Trackr charges £30/season for) | High |
| 3 | Deadlines are only as accurate as the student types them; rolling deadlines can't be represented ("closes when full") | Medium |
| 4 | Status updates, filtering, delete, persistence after reload and calendar export all **work** (tested) | Positive |
| 5 | No per-application notes field in the UI despite a `notes` property; no link from an application to its firm page, mock or practice | Low-Medium |
| 6 | No accessibility violations on the page (axe) | Positive |

**Score: 5 / 10** (vs Trackr: live data on 100+ programmes and alerts).

**To reach 9+:** pick programmes from our firm data with dates, stages and status (open / closed / expected); "opens soon" and "closing soon" email reminders (needs the email provider); support rolling deadlines; per-application checklist linked to the firm's stages and our practice for each stage; notes.
