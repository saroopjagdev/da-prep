# Finance employers: one table per firm

Research date: 2 October 2026 (Phase 1). Each file is a spreadsheet-style table: one row per fact, with a label and a source link.

## Labels

| Label | Meaning |
|---|---|
| OFFICIAL | From the firm's own site, press release, filing, or its own job advert (including its adverts on gov.uk Find an Apprenticeship). |
| MULTI-REPORT | Several independent candidate or prep-site reports agree. |
| SINGLE-REPORT | One candidate or one prep site. |
| JUDGEMENT | Our own opinion or inference. Not a fact. |

## Important limit on how this was researched

This session's network blocks direct page fetches to almost every site (employer sites, gov.uk, Reddit, The Student Room, Glassdoor). Only a web search tool works. It returns the page URL plus a summary of the page written by the search engine. So:

- **Every fact below was seen through a search-result summary of the linked page, not by reading the page.** A label of OFFICIAL means the summary came from the firm's own URL, not that we read it in full.
- Search summaries can merge two pages or two years. Where a summary was unclear about the year or the programme, the row says so.
- Before a fact goes into the app as "official", re-check it on the live page (a person with a browser, or a session with web access allowed).
